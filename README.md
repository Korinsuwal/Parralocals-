# Parralocals – Nike Run Club Style Sport Interval Timer

An athletic interval and HIIT workout timer app styled with the signature **Nike Run Club (NRC)** design language: high-visibility Volt Green (`#CEFF00`), deep carbon black surfaces, giant italic condensed numerals, and the iconic circular **START** button.

---

## ⚡ Key Nike Run Club (NRC) Design Features

### 1. 🏃 Signature Nike Run Club Aesthetic
* **Iconic Volt Green Accent (`#CEFF00`)**: Eye-catching electric neon glow against pitch-black canvas.
* **Giant Athletic Tabular Numbers (`4.8rem` Italic Condensed)**: High-contrast typography readable while sprinting or across a gym/court.
* **Massive Circular "START" Button**: The signature NRC Volt floating circle button (`96×96px`) that transitions to **PAUSE** with live tactile feedback.
* **NRC Metric HUD Grid**: 4-column athletic telemetry bar (`ROUND`, `PACE / PHASE`, `ELAPSED`, `REMAINING`).
* **Radial Sweep Arc**: High-precision circular gauge that tracks interval completion with glowing Volt lighting.

### 2. ⚽ 🥊 ⚡ Sports Categories & Routines
* **⚽ Futsal**: Match Half 20m, Agility Press 45/15, Sprint Burst 30/30, Extra Time 5m.
* **🥊 Boxing**: Championship 12R (3m/1m), Pro Sparring 5R, Heavy Bag 2m, Fight Tabata 20/10.
* **⚡ HIIT**: Tabata Classic 20/10, High-Voltage 45/15, Power Cardio 30/30, Max Burn 60/20.
* **⭐ Custom**: Fast `+` and `−` on-screen steppers for **Work**, **Rest**, **Prep**, and **Rounds**.

### 3. 🔔 Authentic Audio Engine & Bells
* **Exact 0s End Bell Tone**: Resonant ringside boxing bell, referee whistle, acoustic gong, court buzzer, or digital beep at `0:00`.
* **3-Second Warning Alerts**: Triple audio pips at `0:03`, `0:02`, and `0:01` before each phase transition.
* **Web Audio Dynamics Limiter**: Boosts loudness for noisy sports environments.
* **Custom Audio Upload**: Upload your own `.mp3` or `.wav` sound files.

### 4. 🏷️ In-App Club & Brand Customizer
* Tap the logo or `⚙️` to rename the brand (`Parralocals`) and upload your club or gym logo.

## 🚀 How to Run & Share

### Local Testing
* Open [`index.html`](index.html) directly in any browser.
* Or run [`start.bat`](start.bat) to launch the local Wi-Fi server for nearby phones.

### Free Cloud Hosting for Mobile Phones (Netlify Drop)
1. Open **[app.netlify.com/drop](https://app.netlify.com/drop)**.
2. Drag and drop `paralocal_app.zip` (21 KB).
3. Netlify will generate a live HTTPS link to access on any phone.
